## 一、实验目的

1. 在 CentOS 9 虚拟机中安装并启动 Nginx Web 服务器。
2. 学习查询虚拟机 IP 地址和检查端口监听情况。
3. 配置防火墙，使 Windows 主机能够远程访问 Nginx。
4. 修改 Nginx 默认首页内容，实现自定义网页访问。

| Web 服务器 | Nginx 1.20.1 |
| 默认访问端口 | 80 |

## 三、实验步骤

### 1. 安装 Nginx

在 PuTTY 连接虚拟机后执行：

```bash
sudo dnf install -y nginx
```

### 2. 启动 Nginx 并设置开机自启

```bash
sudo systemctl enable --now nginx
sudo systemctl status nginx
```

检查结果显示服务处于 `active (running)` 状态，说明 Nginx 已成功启动。

### 3. 防火墙放行 HTTP 服务

```bash
sudo firewall-cmd --add-service=http --permanent
sudo firewall-cmd --reload
```

执行结果均显示 `success`，说明 80 端口已经允许外部访问。

### 4. 查询虚拟机 IP

```bash
hostname -I
```

也可以通过下面的命令查看网卡信息：

```bash
ip addr
```

本实验中虚拟机网卡 `ens33` 的 IP 地址为：

```text
192.168.190.130
```

### 5. 检查 Nginx 端口监听情况

```bash
sudo ss -tlnp | grep ':80'
```

输出结果显示 Nginx 正在监听 80 端口：

```text
LISTEN 0 511 0.0.0.0:80 ... users:(("nginx",...))
LISTEN 0 511 [::]:80 ... users:(("nginx",...))
```

### 6. 修改 Nginx 首页

CentOS 9 中 Nginx 的默认网页目录为：

```text
/usr/share/nginx/html
```

检查首页文件：

```bash
ls -l /usr/share/nginx/html/
```

发现 `index.html` 是一个指向 CentOS 测试页的符号链接：

```text
index.html -> ../../testpage/index.html
```

删除原来的符号链接：

```bash
sudo unlink /usr/share/nginx/html/index.html
```

创建一个新的首页文件：

```bash
printf '%s\n' '<html><body>hello, njupt</body></html>' | sudo tee /usr/share/nginx/html/index.html
```

检查配置文件并重新加载 Nginx：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

### 7. 验证网页内容

在虚拟机中执行：

```bash
curl -i http://localhost
```

返回结果中包含：

```text
Server: nginx/1.20.1
```

页面内容为：

```html
<html><body>hello, njupt</body></html>
```

在 Windows 浏览器中访问：

```text
http://192.168.190.130
```

页面成功显示：

```text
hello, njupt
```

1. Nginx 安装成功，并能够设置为开机自动启动。
2. Nginx 正常监听 80 端口。
3. 防火墙成功放行 HTTP 服务。
4. Windows 主机可以通过浏览器访问虚拟机中的 Nginx 网页。
5. 原有 CentOS 测试页被替换为自定义页面，最终显示 `hello, njupt`。
