| 项目 | 内容 |

## 三、实验步骤

### 1. 安装 MySQL Server

在 Ubuntu 终端中执行：

```bash
sudo apt update
sudo apt install -y mysql-server
```

### 2. 启动 MySQL 并设置开机自启

```bash
sudo systemctl enable --now mysql
sudo systemctl status mysql
```

检查结果显示服务处于 `active (running)` 状态，说明 MySQL 已成功启动。

### 3. 进入 MySQL

```bash
sudo mysql
```

执行后进入 MySQL 命令行，显示提示符：

```text
mysql>
```

### 4. 创建数据库、用户并授权

在 MySQL 命令行中依次执行：

```sql
CREATE DATABASE mydb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'myuser'@'localhost' IDENTIFIED BY '111111';
GRANT ALL PRIVILEGES ON mydb.* TO 'myuser'@'localhost';
FLUSH PRIVILEGES;
SHOW DATABASES;
```

执行结果中可以看到新建的数据库：

```text
mydb
```

然后退出 MySQL：

```sql
exit;
```

### 5. 验证新用户登录

使用新创建的用户登录：

```bash
mysql -u myuser -p
```

输入密码：

```text
111111
```

登录成功后再次执行：

```sql
SHOW DATABASES;
```

能够看到 `mydb`，说明数据库和用户权限配置成功。

### 6. 安装 DBeaver Community

在 Ubuntu 终端中执行：

```bash
sudo snap install dbeaver-ce --classic
```

安装完成后，在 Ubuntu 应用程序列表中打开：

```text
DBeaver Community
```

首次启动时按照配置向导点击 `Next`，保持默认设置，最后点击 `Apply` 或 `Finish`。

### 7. 配置 DBeaver 数据库连接

在 DBeaver 中新建 MySQL 连接，填写：

```text
Server Host：localhost
Port：3306
Database：mydb
Username：myuser
Password：111111
```

如果提示缺少 MySQL 驱动，点击 `Download` 下载驱动，然后点击 `Test Connection`。

测试连接成功后点击 `Finish`，即可在 DBeaver 中查看 `mydb` 数据库。
