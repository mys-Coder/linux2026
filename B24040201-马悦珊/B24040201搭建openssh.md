## 一、实验目的

1. 在 Linux 虚拟机中安装并开启 OpenSSH Server 服务。
2. 学习查看虚拟机 IP 地址。
3. 使用 PuTTY 从 Windows 远程连接 Linux 虚拟机。
4. 通过远程终端练习 Linux 基础文件操作命令。

## 二、实验环境

| 项目 | 内容 |
| --- | --- |

| 虚拟机软件 | VMware Workstation |

| 虚拟机用户 | mys |
| 远程连接工具 | PuTTY |
| SSH 端口 | 22 |

## 三、实验步骤

### 1. 检查 OpenSSH Server 状态

在虚拟机终端中执行：

```bash
systemctl status sshd
```

检查结果：`sshd.service` 状态为 `active (running)`，说明 OpenSSH Server 已安装并运行。

### 2. 防火墙放行 SSH

CentOS 9 使用 firewalld 防火墙，执行：

```bash
sudo firewall-cmd --add-service=ssh --permanent
sudo firewall-cmd --reload
```

执行结果：

```text
Warning: ALREADY_ENABLED: ssh
success
success
```

说明 SSH 服务已经在防火墙白名单中。

### 3. 查询虚拟机 IP

执行：

```bash
ip addr
```

输出显示网卡 `ens33` 的 IPv4 地址为：

```text
inet 192.168.190.130/24
```

### 4. 使用 PuTTY 远程连接

在 Windows 中打开 PuTTY，配置如下：

- Host Name：192.168.190.130
- Port：22
- Connection type：SSH

点击 Open 后输入用户名 `mys` 和密码，成功登录后出现提示符：

```text
[mys@localhost ~]$
```

### 5. 在远程终端练习 Linux 命令

依次执行以下命令：

```bash
pwd
ls
mkdir njupt
cd njupt
touch hello.txt
ls
echo "I love njupt" > hello.txt
cat hello.txt
```

命令作用：

- `pwd`：显示当前目录，结果为 `/home/mys`
- `ls`：列出主目录中的文件
- `mkdir njupt`：创建名为 `njupt` 的目录
- `cd njupt`：进入 `njupt` 目录
- `touch hello.txt`：创建空文件 `hello.txt`
- `echo "I love njupt" > hello.txt`：将文字写入 `hello.txt`
- `cat hello.txt`：查看文件内容
